# Book Slim - Demo quản lý sách (Slim PHP, MVC)

Môn: Phát triển ứng dụng web mã nguồn mở (kiểm tra lần 2).

## Cài đặt (mỗi thành viên làm một lần)

1. Mở terminal tại thư mục `htdocs` của XAMPP, chạy `git clone <link repo> book-slim`
2. Vào thư mục dự án: `cd book-slim`
3. Chạy `composer install`
4. Mở XAMPP, bật **Apache** và **MySQL**
5. Vào phpMyAdmin (`http://localhost/phpmyadmin`), import `database/schema.sql` rồi `database/seed.sql`
6. Mở `http://localhost/book-slim/public/books` để kiểm tra
